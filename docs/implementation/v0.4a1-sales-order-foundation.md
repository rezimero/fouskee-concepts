# v0.4A1 — Sales Order Control Foundation

## Scope

This slice establishes the first server-authoritative Sales aggregate.

Included:
- organization-scoped sales orders and lines;
- server-resolved customer price list;
- minimum-price / maximum-discount floor enforcement;
- immutable commercial snapshots;
- prepaid versus credit settlement intent;
- concurrency-safe customer credit exposure check;
- generic approval integration for price and credit exceptions;
- maker-checker decisions;
- idempotent order creation;
- RBAC, audit events, API resources and MySQL tests.

Excluded until later slices:
- quotations;
- invoices;
- tax calculation;
- inventory reservation / fulfillment;
- payment allocation;
- cashier sessions / POS;
- refunds / reversals;
- database append-only triggers for Sales evidence.

## Control rules

1. Browser never chooses the authoritative price list.
2. Browser may request a price, but the server calculates whether it breaches
   the effective floor.
3. A below-floor request never auto-approves.
4. A credit order exceeding the customer limit never auto-approves.
5. ApprovalService enforces a distinct checker.
6. Submitted order lines cannot be silently updated or deleted through Eloquent.
7. Sales order creation is idempotent per organization.
8. No stock balance is directly mutated by Sales.
