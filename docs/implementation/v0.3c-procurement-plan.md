# v0.3C Procurement — Implementation Record

## Delivered backend scope

- versioned procurement policy;
- purchase-order creation and approval;
- immutable commercial line snapshots;
- configurable approval threshold;
- partial goods receipts;
- over-receipt tolerance and exception approval;
- lot-ready procurement receipt posting;
- procurement-owned goods-receipt reversal;
- supplier invoice evidence;
- normalized duplicate invoice protection;
- three-way match runs and line evidence;
- cumulative invoice quantity control;
- quantity / price / amount / currency exception detection;
- exception maker-checker approval;
- explicit downstream payment eligibility;
- procurement permissions, audit events, tests, and hardening SQL.

## Deferred to v0.3D

- premium procurement workspace;
- draft PO editing UX;
- receiving scanner UX;
- approval inbox UI;
- match exception investigation UI.

## Deferred to later domains

- supplier payment execution;
- accounts payable journal entries;
- tax determination / recoverability;
- landed-cost allocation;
- foreign-exchange accounting;
- fraud risk scoring.

## Security posture

Procurement never authorizes payment by itself.

Posted receipt corrections use reversal evidence.

Supplier invoice and match evidence lines are immutable.

Database-level evidence triggers are installed as a privileged post-CI step.
