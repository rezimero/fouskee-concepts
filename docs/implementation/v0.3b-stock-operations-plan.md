# v0.3B Stock Operations — Implementation Record

## Delivered scope

- perpetual weighted-average inventory projection;
- inventory value deltas on new movement lines;
- lot-aware balances, receipts, transfers, reservations, and counts;
- stock-count snapshot and variance workflow;
- configurable variance approval threshold;
- generic maker-checker approval foundation;
- controlled transfer orders with transit custody;
- configurable separate receiver rule;
- configurable immediate-transfer policy;
- configurable backdate window;
- projection reconciliation / rebuild command;
- stronger operational evidence immutability;
- API and MySQL feature tests.

## Explicitly deferred

- negative-stock break-glass override;
- sales issue / dispatch posting;
- purchase-order and goods-receipt documents;
- supplier invoices and three-way matching;
- stock-operation frontend workspace;
- FIFO reporting;
- automatic lot allocation;
- expiry alerts.

## Security boundary

Operational documents may change workflow status, but their evidence lines are
immutable after creation.

Movements created by stock-count and stock-transfer workflows are owned by those
documents and cannot be generically reversed through the raw reversal endpoint.
