# Fouskee Concepts Brand Baseline

Approved primary logo direction: green F + orange C intertwined monogram.

## Initial palette
- Fouskee Green: #9BD23C
- Fouskee Orange: #FF8414
- Warm Ivory: #FBF8F0
- Deep Charcoal: #2A241F

Green is the primary brand signal. Orange is an accent and should be used selectively.
