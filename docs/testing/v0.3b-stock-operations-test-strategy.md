# v0.3B Stock Operations Test Strategy

The increment must prove:

- receipt value and weighted-average cost;
- transfer quantity and value conservation;
- missing receipt cost rejection;
- lot creation and lot-scoped balances;
- lot-scoped reservation / transfer behavior;
- small stock-count variance auto-posting;
- large stock-count variance approval;
- maker cannot self-approve;
- stale count rejection after intervening stock movement;
- transit custody during controlled transfer;
- separate receiver enforcement;
- in-transit cancellation return;
- immediate-transfer policy disablement;
- material backdate privileged reason;
- projection drift detection and rebuild;
- operational evidence model immutability;
- owning-document movement reversal protection;
- all pre-existing authentication, audit, commercial, and inventory tests.

After CI is green, privileged database verification must prove direct SQL
UPDATE/DELETE is rejected for movement lines, count evidence lines, and transfer
evidence lines.
