# v0.3D Workspace Test Strategy

## Automated regression gates

Before commit:

1. full Laravel regression on MySQL;
2. Composer validation;
3. frontend ESLint;
4. TypeScript/Vite production build;
5. npm dependency audit;
6. repository source-line gate;
7. `git diff --check`.

No database migration or privileged trigger installation is required because
v0.3D changes presentation and shell contracts only.

## Browser validation gate

After CI is green and before merge, validate in the real authenticated SPA.

### Shell

- MFA gate still redirects correctly;
- desktop grouped sidebar shows only permitted modules;
- tablet collapsed sidebar remains navigable;
- mobile bottom navigation scrolls horizontally;
- existing Customers, Suppliers, Products, Catalog Setup, Price Lists, and
  Sessions routes still work.

### Dashboard

- inventory metrics load for users with `inventory.view`;
- procurement metrics load for users with `procurement.view`;
- inaccessible domains are not fetched or linked;
- module cards route correctly.

### Stock intelligence

- balance rows show product, location, lot, on-hand, reserved, available, WAC,
  and inventory value;
- movement evidence renders source and type;
- search filters without mutating data.

### Stock count

- authorized user can create a count;
- draft can be submitted with a reason;
- material variance cannot be self-approved;
- independent checker can approve/reject;
- view-only user sees no mutation controls.

### Transfer

- draft transfer can be created;
- dispatch moves the document to `in_transit`;
- configured separate-receiver rule is enforced by the server;
- destination receipt completes the workflow;
- cancellation asks for a business reason.

### Procurement

- PO can be created and submitted;
- maker cannot approve their own threshold-controlled order;
- independent checker can approve;
- receiving desk only offers receivable purchase orders;
- partial goods receipt posts correctly;
- over-tolerance receipt shows a visible exception and does not silently post;
- supplier invoice duplicate protection remains server-enforced;
- exact three-way match becomes eligible;
- exception match displays evidence codes;
- maker cannot approve their own exception.

### Regression and accessibility

- sheets close via their explicit close control;
- form labels remain associated with inputs;
- focus states remain visible;
- no horizontal page overflow at supported mobile widths;
- API validation errors remain readable;
- 401/419 handling still follows the central Axios interceptor.

Record browser validation results in the v0.3D handover before merge.
