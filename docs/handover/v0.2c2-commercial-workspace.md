# Handover v0.2C2 — Commercial workspace

## Delivered
- Customer management screen with segmentation, price-list association, and
  credit-limit entry.
- Supplier management screen.
- Product catalog with brands, categories, base units, and multi-unit packaging.
- Catalog setup for brands and product categories.
- Price-list creation and package-level controlled pricing.
- Price floors, discount limits, and mandatory business reasons in the UI.
- Permission-aware desktop and mobile navigation.
- Frontend route guards backed by server-side authorization.
- Read APIs for catalog references and price-list items.
- Audited brand and product-category creation.
- MySQL-backed workspace API tests.

## Deliberate exclusions
Existing master-data records are not silently editable or deletable. Controlled
amendment/archive workflows belong in a later governance increment so historical
commercial context remains explicit.

## Next
After browser validation, Core Domain v0.2 can be closed and the project can move
to Inventory / Procurement v0.3 with ledger-based stock movements.
