## Key decisions

- physical stock uses immutable movement lines;
- no mutable product quantity field;
- balances are rebuildable projections;
- negative stock is blocked by default;
- every posting command is idempotent;
- transaction lines snapshot package conversion;
- reservations are commitments, not movements;
- optional lot/batch support is built into the ledger;
- initial costing direction is perpetual weighted average;
- posted errors are corrected by reversal;
- procurement uses PO -> receipt -> supplier invoice -> three-way match;
- material exceptions use maker-checker controls.

## Review gates before implementation

The lead should challenge the following decisions before 0.3A coding if business requirements require a change:

- weighted-average costing as the initial costing method;
- dedicated transit location for asynchronous transfers;
- negative-stock break-glass policy;
- lot/batch tracking policy;
- approval thresholds and tolerances.

Any material change should be captured in an ADR update rather than becoming an implicit implementation choice.
