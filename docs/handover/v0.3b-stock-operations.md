# Handover — v0.3B Stock Operations

## Baseline

v0.3B extends the merged v0.3A inventory ledger without introducing a mutable
stock quantity field.

## New operational capabilities

### Valuation

New receipts require a base-unit cost.

Every new movement is valued through the central valuation service. Balances
maintain:
- on-hand base quantity;
- inventory value;
- perpetual weighted-average unit cost.

### Lots

Receipt lines may create or reference a lot. Transfer, reservation, and count
commands may reference an existing lot.

Lot-scoped commands never silently consume another lot.

### Stock counts

Stock-count lines snapshot system quantity and cost. Submission validates that
the balance has not changed.

Small variance may post directly. Material variance creates a generic approval
request and requires an independent checker.

### Controlled transfers

`transfer-orders` provide a two-stage physical transfer:
1. source -> system transit location;
2. transit -> destination.

Policy can require the receiver to differ from the dispatcher.

### Policy

Organization inventory policy controls:
- stock-count approval value threshold;
- normal backdate window;
- separate transfer receiver;
- whether immediate transfers remain enabled.

Policy changes require a privileged reason.

### Reconciliation

Use:

`php artisan inventory:reconcile-projections`

Add `--rebuild` only when an operator intentionally wants to reconstruct the
derived projection from immutable movement evidence.

## Database hardening

The repository SQL now includes append-only triggers for:
- `inventory_movements`;
- `inventory_movement_lines`;
- `stock_count_lines`;
- `stock_transfer_lines`.

Because trigger installation requires privileged MySQL credentials, the new
count/transfer triggers are applied in a separate post-CI hardening step.

## Deferred

Negative-stock override remains intentionally unavailable until the fraud-risk
signal and break-glass workflow are ready.

Procurement documents are the next milestone and should reuse the generic
approval service and inventory posting source-reference contract.
