# 0.2B authentication security note

## API throttling

Laravel's API middleware group is explicitly configured to use the named
`api` rate limiter.

The Fouskee limiter applies two simultaneous controls:

- 180 requests per minute per authenticated user, or per guest IP before
  authentication;
- 600 requests per minute per source IP.

This prevents a single authenticated account or source address from consuming
unbounded API capacity while leaving enough burst capacity for the React SPA.

The limiter is defined in `SecurityServiceProvider`, separately from Fortify's
stricter login and two-factor challenge limiters.

Redis-backed rate limiting is deferred until the Redis infrastructure milestone.
