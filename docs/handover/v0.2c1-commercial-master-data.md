# Handover v0.2C1 — Commercial master data

## Delivered
- Organization-scoped customers and suppliers.
- System units of measure.
- Organization-scoped brands and product categories.
- Products with base units and multiple sale/purchase packaging conversions.
- Wholesale/retail-ready price-list foundation.
- Minimum selling price and maximum discount fields.
- Privileged-reason enforcement for price changes.
- Immutable audit events for customer, supplier, product, price-list, and price
  changes.
- New RBAC permissions for customers, suppliers, catalog, and pricing.
- API organization isolation and MySQL-backed feature tests.

## API
Protected routes live below `/api/v1/master-data` and require authenticated,
active, MFA-enrolled users plus domain permissions.

## Deliberate exclusions
- Inventory quantities and stock movements.
- Purchase/sales transactions.
- Taxes and tax profiles.
- Customer credit utilization.
- Product batch/lot tracking.
- Master-data edit/archive UI.

Those capabilities build on these stable references in subsequent milestones.

## Next increment
0.2C2 will provide premium management screens for customers, suppliers, product
catalog, packaging, and price lists, using permission-aware navigation.
